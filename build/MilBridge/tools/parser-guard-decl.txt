# 【危害形态的口径（`D-G143` 的要害；**逐字**）】
#   "解析不出 ⇒ 静默中性化"**本身不是缺陷**。缺陷是**中性值与合法读数不可区分**：
#     · 返回 `(0, 0)`／`0`／`-1` 而当**几何/坐标/尺寸**用 ⇒ **`HARMFUL`**（0 与 -1 都是合法几何值，
#       调用者**无从分辨**"量到 0"与"没量到"）—— 仓外原始案发地正是这个形态（一个**总是**返回
#       `(0, 0)` 的 `wh()`，使整条谓词恒零、正极性永远不成立、整条路被读成"没有该现象"）。
#     · 返回 `None`／`''`／`'?'`／调用者显式传入的默认值之类**哨兵**，且下游**按哨兵判** ⇒ `BENIGN`。
#   `env` 面：`VAR="${ENV:-default}"` 的值若**只被"用即校验"**（拿去做一次会**响亮失败**的操作）
#   ⇒ `BENIGN`；若被当作**读数**参与比较而**无格式白名单** ⇒ `HARMFUL`。
#
# 【本波做过的一次**形态收窄**（如实登记，因为它决定射程）】
#   初版 `parser` 形态里含一条很宽的 `or 0\)`。**现读实测：它在现仓上命中 4 处，全部是
#   表格单元格的默认值**（把一个可选列缺省成 0），**不是**解析失败回退 ⇒ 那 4 处会被误判红
#   ⇒ **泛红的判据会被读成"世界如此"**。故本波**删掉该形态**，只留"解析失败即回退成中性
#   **数值/坐标**"的形态。收窄后现读 `sites_parser=0`（见射程表后的结论）。
#   ⇒ 判据的形态集**故意保守**：宁可漏掉"表格默认值"这类边缘形态，也不产出假红。
