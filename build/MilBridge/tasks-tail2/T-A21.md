# 任务 T-A21 · 托管侧「会话句柄面／段落模型」可提供性 —— 只读侦察 ＋ 设计

## ① 任务目标
你是本项目的**只读侦察/设计**子代理。`T-A6`/`T-A20` 现取结论：native 域**合法终点** —— 剩余缺口（`FsQuerySubtrackDetails`／`FsQueryTrackParaList`／`FsQueryTextDetails`）的**入参面均需托管句柄**（如 `para=0x4` 为托管句柄，本侧不可认领）。本任务查**托管侧**能否提供。回答：

1. **现取**：这些入口的托管**调用点**（`build/PresentationFramework.Linux/**` ＋ `upstream/wpf/**` 的 `.cs`）与**实参来源**（`_paraHandle`／`Handle`／表索引）；`para=0x4` 到底是谁产出的（`PtsHost.CreateHandle`？）。
2. **`PtsHost`/`PtsCache` 的句柄面**：托管侧是否已有「会话句柄 → 对象」的反查/导出面（只读）；native 若拿到该句柄，**能否**合法使用（跨调用持有 vs 调用期有效；照裁定四十五）。
3. **候选路**（逐条给 可及性∧可行性∧代价∧`P8`落点）：
   - (甲) 托管侧在**不缺省关**的前提下把所需句柄/表**备好**（native 只读消费）；
   - (乙) native 经**已有回调**（`fscbk` 槽）主动获得句柄；
   - (丙) 其它。
4. **结论**：可行（给设计草案 ＋ 判据草案 ≥3 条 ＋ 反极性）／不可行（具名 `PRECOND-*` ＋ 合法终点）。
