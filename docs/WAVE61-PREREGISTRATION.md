### 2.3 件③ `TASK-0711`（方案 A）：仓内 runner 的**首写点截断**

- **缺陷**：runner 用 `>>` 追加 ⇒ 同一文件被跑第 N 趟时**行数一直涨**，越过冻结器的行数上限 ⇒ **冻结器拦**。

- **判据（落地后验收）**：同一件连跑两趟 ⇒ 文件行数**不再单调增长**（第一趟的行数 == 第二趟的行数）；
  反极性 = 退掉这 `+4/−1` ⇒ 行数重新增长（**成对**）。
