## §1 四要件（**逐字文本，可直接抄进任何预登记**）

> 抄的时候**一个字都别改**（含反引号与箭头）。这四件是**合取**：**缺一即只能记 `NOINFO`**，
> 而 `NOINFO` **既不算绿也不算红**。

**① 两臂同刻**

    ① **两臂同刻**：同一装置、同一会话、**只换一个件**；两臂**交替**跑，且两个件都在**跑之前**带
       `sha256sum` 前置断言（`sha16` 写进判据，事后补的不算）。**不许跨时刻比**（"昨天新件红、今天旧件绿"
       这种跨会话拼接**不是**两臂读数）。

**② 成对归因臂**

    ② **成对归因臂**：同一条腿在旧件/新件上**各跑一遍**成对，对与对之间**交替先后**（不是"先把旧件跑完
       再跑新件"），**每趟全新进程树**（不许复用常驻进程/缓存）。对数 `N` **先写死**，跑完不许改。

**③ 复现性**

    ③ **复现性**：该红必须**可复现**（确定性判据逐位可分，或在新件上重复出现）。
       ⚠️ **若该红在旧件上也能复现同一形态 ⇒ 不得称"本波引入"** —— 那只能记"**既有现象的复现**"；
       两臂速率**都判不出差别**时，判词就是 **`OK`（不是回归）**（这就是 `D-G99` 的**假红**方向，必须拦住）。
       ⚠️ **③ 的自洽守卫（必须同时满足；与计数矛盾 ⇒ 拒绝）**：`--old-repro` 的**值**必须与**旧臂实测红数**自洽 ——
       `old_repro = yes ⇒ 旧臂红数 > 0`；`old_repro = no ⇒ 旧臂红数 == 0`。
       **违反 ⇒ `rc=2` ＋ `REGDEC_REFUSE=repro-inconsistent(…)` 点名（拒绝），不许悄悄换一条判词路径**。
       理由 = **与分母那一格同构**（`D-G94`）：两者都是「**要件值与计数自相矛盾 ⇒ 分母/归因不可信**」。
       ⚠️ **为什么必须写死**（现场机械证；⚠️ 下列读数是**修前**读数，用来解释本条**为什么存在**）：
       修前 `--old-repro yes` ＋ 旧臂 `0/5` ⇒ 判 `REGRESSION (rate-aggravated)`，其理由文字断言「**旧件也红**」，
       与**同一屏**的 `REGDEC_TABLE old=0/5` **直接矛盾**；修前 `--old-repro no` ＋ 旧臂 `3/16` ⇒ 子类名
       `statistical-new-only` 是**假分类**（`D-G104` 族：读数器输出语义被读错）。
       ✅ **已修（`#58`，车道 W150A，dated）**：修后同两条命令 ⇒ `REGRESSION_DECISION=NOINFO` ∧ `rc=2` ∧
       `REGDEC_REFUSE=repro-inconsistent`；判据与两极化读数见 `#58` 报告（`~/w150a/criteria.md`）。

**④ 统计口径**

    ④ **统计口径**：**Fisher 精确检验 · 双尾**（2×2 表、固定边缘、超几何零分布；**双尾 = 所有"概率 ≤ 观测表概率"
       的表的概率之和**，不是 `2×单侧`）。**分母只算"真尝试过的趟"**（`D-G94`：`SKIP dead`／"没点"的趟
       **不许进分母**，进了就是**读数不可归因**）。**趟数与功效必须先写**（`D-G99`）：先写死每臂报多少趟、
       目标功效多少，再报读数；**p > α 且旧件 0 红 ⇒ 分不开"随机"与"件相关" ⇒ `NOINFO`**，**不许**判回归。
       **缺任何一件 ⇒ `NOINFO`**。
       ⚠️ **`p` 报几位（写死，别各写各的）**：**机器行按工具现印**（`REGDEC_FISHER p=` 用 `%.6f`），
       **人读引用统一 3 位小数**（与 `--selftest` 的 `want3=` 口径、本件 `§4` 的表一致）。
       🔴 **铁律：判「是否 `≤ alpha`」必须用机器行的原值，绝不许用四舍五入后的 3 位。**
       现场真实危险窗：`0/25 vs 5/25 ⇒ p = 0.050152`，工具判 **`NOINFO`**（**正确**，`0.050152 > 0.05`），
       而三位小数 = `0.050` ⇒ 人读会读成「`≤ 0.05` ⇒ `REGRESSION`」⇒ **判词被显示位数翻转**。
       ⚠️ **表型要说全**：`p` 来自 **2×2 非配对表**「臂 × 红/不红」（工具自报 `two_tailed=yes
       method=hypergeometric-le-observed`）；`--pairs`／`--pair-*` **只做归因一致性核对**、
       **不参与** `p` 的计算 ⇒ 引用时**不许**把它读成配对检验（`McNemar`）。

**判词口径（三态，写进预登记）**

    **判词三态**：`REGRESSION`（回归）｜`NOINFO`（要件缺一／样本不足／功效不足 ⇒ **既不算绿也不算红**）｜
       `OK`（判得出"不是回归"）。**判据件** = `build/MilBridge/tools/regression-decision.py`
       （`--selftest` 自带两极化；机读行 `REGRESSION_DECISION=` ＋ `rc`）。
    ⚠️ **三态的词表映射（两套词指同一件事，落地必须写死）**：
      | 任务书/历史报告用词 | 工具机读行用词 | 含义 | `rc` |
      |---|---|---|---|
      | **`PASS`** | **`OK`** | 判得出「不是回归」 | `0` |
      | **`FAIL`** | **`REGRESSION`** | 判回归（子类 `rate-aggravated`／`deterministic-new-only`／`statistical-new-only`） | `0` |
      | **`NOINFO`** | **`NOINFO`** | 要件缺一／样本不足／功效不足／分母不合规 ⇒ **既不算绿也不算红** | `3` 证据不足／`2` 分母不合规 |
      依据：`build/MilBridge/W105A-report.md:21` 写的是 **`C1 = FAIL`（判据逐字执行）**，而该件 §4.5 的 `F1`
      正是「不许把间歇判成回归」⇒ **历史件的 `FAIL` = 回归 = 工具的 `REGRESSION`**。

## §2 为什么现行写法不够（**三条现场读数，不是推断**）

1. **单腿推理分不开"件相关"与"随机"**（`D-G99`，来源 = 车道 `W105A` §4.5 自立的 `F1`）：
   `W105A` 判据 `§4 C3` **原文**写 *"若 **A 臂红而 B 臂同腿绿** ⇒ 单变量归因成立 ⇒ 判 `C1 = FAIL`（回归）"*。
   实测：A 臂三条红腿在 B 臂同腿全绿（按**字面**该判"回归"），但 **B 臂自己在另一条腿上红了同一形态**；
   当代合计 **新 `3/36` vs 旧 `2/36` ⇒ Fisher 双尾 `p = 1.000`** ⇒ **判不出差别**。
   ⇒ **一条腿一个样本**给出的不是证据，是**噪声**。
2. **分母口径会把"命中"自己剔掉**（`D-G94`）：`W98A` 的先写判据里 `clicks_total = grep -c '^CLICK '`（**含** `SKIP dead`），
   于是本批**唯一一次**真命中逐击 = 前 7 击全落地 ＋ 2 击 `SKIP dead` ⇒ `7/9 = 77.8% < 80%` ⇒ 被判"**无检测力**"、
   该趟**被从分母里剔除** ⇒ 那次 `rc=139` ＋ **核心转储**就看不见了。修后（分母换 `tried`）：`7/7 = 100%` ⇒ `detect=yes`。
3. **样本量是硬约束，不是态度问题**（三条现场红率并列）：`W105A` 的 `R2` 腿 **`4/30`**｜
   `W112A` 修前 **`2/16 = 12.5%`**｜`W114A` 修前 **`1/17 = 5.9%` → 修后 `1/16 = 6.2%`**（Fisher 双尾 `p = 1.00`）。
   ⇒ **6% 量级的间歇红率下，十几腿/臂判不出任何东西**；工具现算的所需趟数见 `§4`。

## §4 现算的样本量参考（⚠️ **每次都要现场重算，别抄这几个数**）

工具现算（`Fisher 双尾 · alpha=0.05 · 功效 0.80 · 等臂`；命令见报告 §3）：

| 要分辨的差别（旧→新） | 所需趟数/臂 | 备注 |
|---|---|---|
| `0% → 6%` | **131** | 本波现场那档（`W114A` 修后红率 `6.2%`） |
| `0% → 6.25%` | **126** | 同上，按 `1/16` 的点估计 |
| `0% → 5.9%` | **133** | `W114A` 修前点估计 |
| `0% → 10%` | **78** | |
| `0% → 12.5%` | **62** | `W112A` 修前点估计 |

**两个容易混的口径，别互相替代**：

- **功效口径**（上表）：要**分辨**两个速率需要多少趟。
- **区间口径**：`0/N` 的 **95% 单侧上界** = `1 − 0.05^(1/N)` ⇒ `0/16 ⇒ 17.1%`、`0/30 ⇒ 9.5%`、`0/40 ⇒ 7.2%`、`0/49 ⇒ 5.9%`。
  它回答的是"**旧件真是 0 红时，它的速率最多能有多高**"。仓内此前那句"**≥40 腿/臂**"走的是**这条**口径
  （要有 40 腿才能把旧件的速率上界压到 7.2%，低于修前点估计）——**不是** Fisher 功效口径的 131 腿。**两个数都留着、都要报**。

**"16 腿能判什么"（本波现场那格，工具现印）**：`N=16`、旧臂 `0/16` 时，
`MDE = 0.385` —— 即**只有新臂红率 ≥ 约 38.5%** 才谈得上显著；观测到的是 `1/16 = 6.25%` ⇒ **`NOINFO`**。
（同一件事的另一种说法：旧臂 `0/16` 时，新臂至少要 **5 红**（`p = 0.0434`）才显著。）

## §5 怎么用那把牙（`regression-decision.py`）

    python3 build/MilBridge/tools/regression-decision.py \
      --old <旧件红>/<旧件真尝试趟数> --new <新件红>/<新件真尝试趟数> \
      --pairs <成对臂对数> [--pair-both R --pair-old-only R --pair-new-only R] \
      --same-time --old-sha16 <…> --new-sha16 <…> --old-repro yes|no \
      --planned-legs <先写的趟数> --planned-power 0.80 \
      [--alt-old <P> --alt-new <P>] [--json]
    python3 build/MilBridge/tools/regression-decision.py --selftest

- 机读行：`REGRESSION_DECISION=REGRESSION|NOINFO|OK`（**恰好一行**）＋ `REGDEC_RC=` ＋ `REGDEC_FISHER p=` ＋
  `REGDEC_PAIRED/REGDEC_MDE/REGDEC_REQUIRED_N_OBS` ＋ `REGDEC_REASON reason=…`。
- `rc`：`REGRESSION`/`OK` ⇒ `0`；`NOINFO`（证据不足）⇒ **`3`**；**分母口径不合规**（`D-G94`）⇒ **`2`** 且印
  `REGDEC_REFUSE=…`（点名"分母不是真尝试过的趟"）。**`rc≠0` 一律不算绿。**
- ⚠️ **`NOINFO` 不是第四态**：`rc=2` 与 `rc=3` 印的都是 `NOINFO` 这一个词，区别只在**原因码**
  （`rc=2` = 连分母都不可信；`rc=3` = 分母可信但证据不足）。
- ⚠️ **观测后功效（`REGDEC_POWER_NOW`）只作诊断、不当门**：它是 `p` 值的单调函数，拿它当门 = **偷偷把 `alpha` 改小**。
  当门的是**先写的计划**（`--planned-legs` 必须等于现场成对臂对数、`--planned-power ≥ 目标功效`）。
